03 CPSA Diagnostic Framework
Five independent lenses. Each measures a discrete failure mode.
All scores are composited into a single Diagnostic Score (0–100).
S

Structure

Information architecture, layout hierarchy, grid fidelity, and navigational logic. Evaluates whether users can model the interface mentally.

F

Flow

Task progression, state transitions, interaction sequencing, and depth navigation. Measures directional clarity across user journeys.

F

Feedback

System response to user input: hover states, loading indicators, error handling, confirmation signals, and microinteraction quality.

R

Readability

Typography hierarchy, contrast ratios, information density, scan-path optimisation, and cognitive load management.

C

Consistency

Component pattern coherence, spacing rhythm, colour system discipline, and inter-state visual logic. Identifies design system drift.
